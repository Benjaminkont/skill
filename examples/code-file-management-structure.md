# 代码文件管理知识树结构

```
代码文件管理（编程语言中的代码组织方式）
│
├── 文件与目录组织
│   ├── 源文件类型（.cpp/.py/.java）
│   ├── 头文件/接口文件（.h/.hpp）
│   ├── 目录结构约定
│   └── 包/模块路径映射
│
├── 代码单元划分 ★ 本次起点
│   ├── C++: 声明与实现分离（.h + .cpp）
│   ├── Python: 单文件即模块（.py）
│   └── Java: 类与文件绑定（一文件一公共类）
│
├── 命名空间与作用域
│   ├── C++: namespace
│   ├── Python: 模块即命名空间
│   └── Java: package
│
├── 依赖引入机制
│   ├── C++: #include（编译时文本替换）
│   ├── Python: import（运行时加载）
│   └── Java: import（编译时解析）
│
└── 编译与链接模型
    ├── C++: 分离编译 + 链接器
    ├── Python: 无编译（解释执行）
    └── Java: 字节码编译 + 类加载器
```
