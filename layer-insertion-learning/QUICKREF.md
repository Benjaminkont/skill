# 层插学习法速查

本页概括 [SKILL.md](SKILL.md)，不增加独立规则。

1. **定对象与疑惑。** 区分概念、实例和机制，明确本轮想理解什么。
2. **先准备网络。** 从共享库 `INDEX.md` 按名称、别名、术语与范围找候选，读正文确认；已有范围内补节点，没有适用网络才新建并登记。准备系统骨架和当前对象附近的细节。
3. **写完整讲义。** 考虑同层 → 向上 → 跨系统 → 向下，呈现顺序由内容决定。四方向均覆盖，不适用的说明原因；不设层数、数量和章节配额。
4. **自然过渡并返回。** 说明比较依据，用反问引出联系后接着解释；新关系帮助理解当前对象，展开后回到原问题。自检题及答案按需附，不阻塞讲解。
5. **保存并交付。** 讲义默认写到工作目录的 `layer-insertion-docs/`，使用有效网络链接；对话概述并告知网络变更。真实试用记录到 [TODO.md](TODO.md)。

| 方向 | 要回答的问题 |
|---|---|
| 同层 | 在当前比较视角下，哪些对象解决共同问题或承担共同角色，差异是什么？ |
| 向上 | 它属于什么整体，谁使用或管理它，为什么需要它？ |
| 跨系统 | 熟悉系统中的哪个特征能帮助理解，哪些地方不能照搬？ |
| 向下 | 它由什么组成、如何运行，限制从哪里来？ |
