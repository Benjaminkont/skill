这是可选的组织示例，不是待填写的必需章节。标题、顺序、篇幅由本轮内容决定，四方向的要求以 [SKILL.md](SKILL.md) 为准。下面用 Java import 展示如何把方法融入内容。

## import 为什么能让类名变短

直接解释普通 Java 类型导入的作用：让源文件中可以用简单名指代相应类型，帮助编译器解析名称。先区分 `package` 声明所属包、`import` 引入名称，以及全限定名直接写明所指类型。

## 从源文件到编译器的名称解析

用一个小例子说明名称在哪个源文件中生效、怎样参与编译。沿“完整类名 → 导入声明 → 简单名引用”解释过程，让读者理解 import 为什么不等于复制源码或安装依赖。

## Python 也有 import，可以照搬理解吗

借学习者熟悉的 Python 名称引入建立联系，立即指出运行时模块加载与 Java 编译期名称解析的差异。只借有用的对应；若学习者背景或主题不支持可靠类比，改为简短说明这一方向不适用。
