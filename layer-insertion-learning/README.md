# 层插学习法

> 在知识空间中动态导航，从一个亮点看见它所在的世界

## 这是什么

层插学习法是一种**认知导航方法**，帮助理解陌生的概念、技术或现象。它不是简单的"自上而下"或"自下而上"，而是从学习者遇到的具体起点出发，通过四个方向探索周围的知识空间：

1. **同层对照**：看看同房间的兄弟，通过对比理解差异
2. **向上抽取**：看谁在使用它，理解设计动机
3. **跨系统类比**：借另一个系统理解，但警告差异
4. **向下深入**：看内部结构，理解如何实现

## 为什么需要它

**传统学习方法的问题**：
- 线性教程：从头到尾，但你只想理解某个点
- 文档查阅：定义准确，但缺少上下文
- 实例演示：知道怎么用，但不知道为什么

**层插学习法的优势**：
- ✅ 从你实际遇到的问题出发
- ✅ 动态选择探索方向（不是固定路线）
- ✅ 建立多维度的理解（不只是定义）
- ✅ 明确边界和限制（知道不能做什么）

## 适用场景

**适合**：
- 理解具体的概念（"Docker 容器是什么"）
- 理解技术决策（"为什么用 Redis 而不是 Memcached"）
- 理解系统组成（"Kubernetes Pod 在整个系统中的角色"）

**不适合**：
- 宽泛的学习目标（"学习后端开发"）
- 纯操作步骤（"如何安装 Node.js"）
- 快速查询（"这个参数是什么类型"）
- 故障排查（"为什么这个 API 报错"）

## 快速开始

### 1. 确定起点
学习者已经遇到了某个具体的概念，想要理解它。

### 2. 构建知识树
画出起点所在的树结构，明确它在哪个"房间"：

```
系统
└── 容器
    ├── 组件 A
    ├── 你的起点 ★
    └── 组件 B
```

### 3. 选择方向探索
- **同层**：看组件 A、B 与起点的关系
- **向上**：看容器如何使用起点
- **跨系统**：借其他系统类比
- **向下**：看起点的内部结构

### 4. 查看案例
案例库在本 skill 的 `examples/` 目录下（随 skill 安装，不在你的项目目录里）：
- `qdrant-point-v2.md`：理解 Qdrant 的 Point
- `sqlite-row-v2.md`：理解 SQLite 的 Row
- `async-v2.md`：理解"异步"
- `git-stash.md` / `git-branch-merge.md`：理解具体命令，共用 `git-structure.md`

### 5. 产物写到哪里
讲解文档与新建的知识树写到**工作目录**下的 `layer-insertion-docs/`：
- 不要写进 skill 安装目录（那是共享的方法与案例来源）
- 只有用户明确要"扩充案例库"时，才写 skill 目录的 `examples/`，且先确认

## 目录结构

```
layer-insertion-learning/          # skill 目录
├── SKILL.md           # 完整方法论
├── README.md          # 本文件
├── TEMPLATE.md        # 输出模板
├── QUICKREF.md        # 快速参考
├── TODO.md            # 优化方向
├── examples/          # 案例库（只读；扩充需用户确认）
│   ├── *-structure.md # 知识树结构
│   ├── *-v2.md        # 完整案例
│   └── *.md           # 早期案例
└── demo/              # 可视化演示
    └── layer-insertion-learning/
        └── enhanced.html
```

> 注意：本仓库里 `examples/`、`demo/` 位于仓库根目录，打包安装时才装配进上述 skill 目录。文档中凡写 `examples/xxx.md`，一律相对 **SKILL.md 所在目录**解析，不要相对当前工作目录。

## 核心概念

### 知识树
起点所在的树形结构，明确"房间"和"兄弟"：
- **同层 = 同房间**：共同父节点的兄弟
- **深度相同 ≠ 同层**：不同分支不算同层
- **层有作用域**：层不是无限平面

### 四个方向
1. **同层对照**：最小对比集（2-3 个），覆盖主要差异
2. **向上抽取**：容器层 + 操作层（+ 理论层待扩展）
3. **跨系统类比**：明确借用范围，主动指出差异
4. **向下深入**：内部组成、存储结构、实现机制

### 探索策略
- **默认优先级**：同层 → 向上 → 跨系统 → 向下
- **动态调整**：没有合适内容就跳过，不硬凑
- **递归控制**：默认只递归一层，依用户兴趣深入

## 如何使用

### 作为学习者
1. 遇到陌生概念时，用层插法主动探索
2. 参考 `examples/` 中的案例结构
3. 构建自己的知识树

### 作为讲解者
1. 阅读 `SKILL.md` 理解完整方法论
2. 使用 `TEMPLATE.md` 组织讲解内容
3. 参考 `QUICKREF.md` 快速决策

### 作为 AI
1. 识别学习者的起点
2. 构建知识树（内部步骤；可参考 skill 内的 `*-structure.md`，路径相对 SKILL.md 所在目录）
3. 默认直接在对话里讲解；需要文档时按模板输出到工作目录 `layer-insertion-docs/`（参考 `*-v2.md` 案例）
