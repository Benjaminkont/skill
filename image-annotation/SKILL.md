# 图片标注

在真实底图上叠加可编辑标注。默认采用 SVG，供阅读和笔记使用时再导出 PNG；用户指定其他格式或绘图工具时遵从其选择。框、箭头、文字采用确定性的绘制方法，无需图像生成模型。

## 工作流程

1. **明确图的任务**：确定要指认的对象、区域和说明；软件截图记录选中对象、当前模式、已展开菜单以及禁用状态。一张图宜聚焦一个主题，标注过密时拆图。
2. **取得并查看原图**：使用用户提供的图片或获准采集的实际截图，保存原件；新拍截图时避免鼠标、提示框和未展开菜单遮挡目标。截图工具如何操作遵循当前环境的工具规范。
3. **裁切与定位**：保留分组标题等必要上下文，通常先保持 1:1 像素裁切。坐标从实际图片像素取得；工具展示的预览若被缩小，先按原始宽高换算，不能直接套用预览坐标。
4. **编写标注数据**：记录来源、裁切范围、框选区域、编号和说明。目标位置由图像观察确定，说明含义由实际界面或可靠资料核对；脚本不会自动识别控件或验证用途。
5. **生成 SVG**：保持底图内容不变，叠加框、线、箭头、编号与文字。默认说明放在截图外侧，避免遮住界面；按空间顺序编号，减少箭头交叉。颜色、线宽、字体保持同组图片一致。
6. **渲染与检查**：导出 PNG 并实际查看。检查框是否包住正确区域、箭头是否明确、文字有无缺字或溢出；核对禁用状态和解释准确性，并在文档实际显示宽度下检查可读性。不能仅凭 SVG XML 有效就宣布画面检查通过。
7. **交付与关联**：交付原图、SVG 和按需导出的 PNG，保留标注数据方便更新。用户要求更新笔记时才修改正文，图旁注明必要对象与状态并附原图链接；其他情况只交付标注成品。

## 绘制约定

- 原图另存，标注图使用新文件名；不要无请求覆盖现有图片。
- 推荐 SVG 内嵌 PNG 底图，方便独立交付；SVG 的文本、框线可缩放，截图本身仍受原始分辨率限制。
- 中文字体需要在渲染环境中存在；SVG 在另一台设备打开时可能替换字体，PNG 固定最终显示效果。
- 框留少量边距，箭头指向框的边缘；文字尽量放在外侧说明卡片。左右摆放不是强制要求，以目标分布和阅读顺序为准。
- 不添加截图中没有的控件，不把推测当作已验证事实，不将渲染后的示意内容称为原始截图。
- 不默认使用 Quick Look 缩略图作为最终 PNG：缩略图可能裁切画布；需要核对输出尺寸和完整性。

## 可复用工具

普通的左侧说明、右侧图片布局可用 [scripts/annotate.py](scripts/annotate.py)。它读取 JSON，按原图坐标裁切并生成自包含 SVG；不会修改来源文件，也不覆盖已有输出。需要 Pillow，指定 PNG 输出时另需 CairoSVG 与系统 Cairo。

使用脚本时读取 [references/spec.md](references/spec.md)，其中包含配置格式、运行方式和渲染依赖说明。复杂布局可直接编辑 SVG 或另用用户选择的矢量工具，不必迁就脚本模板。

完成前确认：目标与说明逐项对应、图未截断、字体完整、SVG 和 PNG 一致、项目内引用均可访问。简要说明实际交付了哪些格式，以及尚未完成的检查。
