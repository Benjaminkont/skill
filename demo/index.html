01 / 进入

从 a 开始

遇到一个陌生事物，先给出它的直接定义，建立最初的认识。

02 / 展开

照亮周围

借同层事物和跨项目的弱对照，反过来理解 a 的作用与边界。

03 / 抽插

换层，再展开

理解上层接口 b 做什么，以 b 为新的起点，在 B 层重复这个过程。

周围的知识，为理解当前事物服务。a → A ⇢ x / X ⇢ p / P → b → B → …

本页将当前讨论可视化；a、b、c、x、p 与层名均为抽象示意。层亮起表示周围事物进入理解视野，不表示已经掌握整层；变暗表示注意力已经移开。这里只演示“是什么”的探索过程，尚未确立完整学习 SOP。
